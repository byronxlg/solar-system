# solar-system

A solar system you fly through with your hands and a gong you bang with them: Vite + React,
MediaPipe tracking in the browser, a static site on GitHub Pages at
https://byronxlg.com/solar-system/ and https://byronxlg.com/solar-system/gong/.

Operational docs live in `runbook/` (`README.md` for what it is and what healthy means,
`updates.md` for how change ships and rolls back). Working rules are in `.claude/rules/`;
the README describes the apps and the controls.
